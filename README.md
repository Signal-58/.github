# Signal-58 organisation defaults

Default community health files for repositories in the Signal-58 GitHub organisation. GitHub uses a file from here for any repository that doesn't have its own.

- `pull_request_template.md`: the default pull request description. Its `OP#` line links the pull request to an OpenProject work package.

This repository has to be public for GitHub to apply the defaults. Keep it to templates only: nothing private belongs here.
